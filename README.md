# Atwood Dsigns website

Static site for Atwood Dsigns, an interior design and build studio in Kokapet, Hyderabad.
No framework and no build server: every page is plain HTML generated by one Python script.

- Journal posts are written in the Sanity Studio at https://atwood-dsigns.sanity.studio (project `xbvaq1gt`, code in `studio/`; `cd studio && npm run dev` / `npm run deploy`). `tools/cms.py` fetches them during the build, and each post becomes `journal-<slug>.html`. The build therefore needs the internet.
- `.github/workflows/deploy.yml` builds `main` on every push, on every Sanity publish (webhook) and hourly, and commits the finished site to the `deploy` branch.
- `tools/build.py` holds all other page content and the photograph table (`PHOTOS`). Edit it, then run `python3 tools/build.py`. Never edit the generated `.html` files.
- `ASSETS.md` is generated by the build: every photograph, where it came from, its focal point and where it is used.
- `assets/css/styles.css` is the design system, "Atelier": tokens, type (Bodoni Moda for display with its italic for emphasis, Jost for text), grid, every page's layout, and the motion choreography (section 26).
- `assets/js/main.js` is the behaviour, with no dependencies: header, menu, the ten-stage journey (a dotted path drawn through the stage markers, measured from the layout, drawn in full under reduced motion), portfolio filter and lightbox, services section links, enquiry form, and the motion system: scroll reveals (IntersectionObserver, including the staggered mask reveal of the home page room gallery), the home hero and project openings, restrained parallax, the pinned horizontal reel of selected work (1000px and up), and a "View" label that follows the pointer over projects. Page transitions are native cross-document View Transitions in the stylesheet. Motion only switches on when the visitor has not asked for reduced motion; without it, or without JavaScript, every page is complete and still.
- New photographs need an 800px copy next to them (`name-800.jpg`) for phones and thumbnails. Then run `python3 tools/webp.py` (needs Pillow) to write WebP copies, which the pages serve first.

Content rules:
- Photographs marked `"library"` in `PHOTOS` came with the previous website and are most likely stock. They are never shown where they would imply the studio designed or built the space.
- Client quotations are kept in `QUOTES` but published only when `SHOW_QUOTES = True`, once the studio confirms they are from real clients.
