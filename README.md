# Atwood Dsigns website

Static site for Atwood Dsigns, an interior design and build studio in Kokapet, Hyderabad.
No framework and no build server: the eight pages are plain HTML generated by one Python script.

- `tools/build.py` holds all page content and the photograph table (`PHOTOS`). Edit it, then run `python3 tools/build.py`.
- `ASSETS.md` is generated by the build: every photograph, where it came from, its focal point and where it is used.
- `assets/css/styles.css` is the design system (tokens, grid, components, motion).
- `assets/js/main.js` is the behaviour (reveals, slideshow, drawn-and-built slider, stages timeline, portfolio filter and viewer, menu, enquiry form).
- New photographs need an 800px copy next to them (`name-800.jpg`) for phones and thumbnails.
